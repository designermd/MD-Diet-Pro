MD&SA Challenge Diet V3.1

الجديد في V3:
- اسم التطبيق صار MD&SA Challenge Diet.
- إضافة اللوغو داخل الهيدر.
- خانة "شو أكلت اليوم؟" مع إمكانية تسجيل اسم الأكلة، الكمية، الوزن بالغرام، وسعرات 100غ.
- قائمة أطعمة سريعة شائعة مع سعرات 100غ جاهزة.
- خيار Free Meal لكل صنف تضيفه.
- حساب سعرات اليوم المأكولة، السعرات الحرة، والسعرات المتبقية من الهدف.
- بقاء الوجبات المقترحة والتنبيهات المحلية.
- زر أكلت الوجبة + تبديل الوجبة.
- تسجيل وزن + رسم بياني.
- versionCode 3 / versionName 3.0

طريقة البناء على GitHub:
1) استبدل ملفات المشروع الحالي بمحتويات هذا المشروع.
2) تأكد أن .github/workflows/build-apk.yml موجود.
3) Commit changes.
4) Actions > Build APK > Run workflow.
5) بعد النجاح نزّل Artifact باسم MDSA-Challenge-Diet-V3-APK.
6) فك الضغط وثبّت app-debug.apk فوق النسخة الحالية.
