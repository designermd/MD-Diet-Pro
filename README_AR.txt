MD Diet Pro Android

هذا المشروع جاهز للبناء على GitHub بدون Android Studio.

بعد رفع الملفات إلى GitHub:
1. افتح تبويب Actions.
2. اختر Build APK.
3. اضغط Run workflow.
4. انتظر انتهاء البناء وظهور علامة صح خضراء.
5. افتح آخر Build.
6. من قسم Artifacts نزّل MD-Diet-Pro-APK.
7. فك الضغط وستجد app-debug.apk.
8. أرسله إلى هاتف Android وثبّته.
9. عند أول تشغيل وافق على إذن الإشعارات.

مهم:
- التطبيق مخصص للبالغين 18+.
- الإشعارات محلية ولا تحتاج إنترنت بعد التثبيت.
- بعض أجهزة Android قد تؤخر الإشعارات بسبب Battery Optimization. إذا لاحظت تأخيراً، اسمح للتطبيق بالعمل في الخلفية.
